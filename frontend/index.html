Academic Overview

Project Objectives

Objective 01
Detect faces from uploaded event photographs using Multi-task Cascaded Convolutional Networks (MTCNN).
Objective 02
Generate deep facial embeddings (512-dimensional feature vectors) using FaceNet neural network.
Objective 03
Index facial embeddings efficiently to enable rapid similarity search across large photo collections.
Objective 04
Retrieve matching event photographs instantly using cosine distance similarity metrics.
Objective 05
Provide an intuitive, responsive web interface for photographers and event attendees.
