Technical Architecture Reference

Deep Learning Architecture & Mathematics

Formulations for facial feature embedding, landmark warping, MTCNN cascades, and DBSCAN clustering.

1. Face Detection & Affine Landmark Alignment (MTCNN)

Images pass through a three-stage network (P-Net proposal, R-Net refinement, O-Net landmark localization) detecting 5 key landmarks (eyes, nose, mouth corners). The face crop is warped using an affine transformation to normalize inter-ocular distance and head rotation before feeding into the embedding network.

2. Inception-ResNet FaceNet Metric Learning & Triplet Loss

A Deep Convolutional Neural Network $f(x) \in \mathbb{R}^{512}$ maps aligned face images to a 512-dimensional unit hyper-sphere ($\|f(x)\|_2 = 1$). The network is optimized via **Triplet Loss**:

L = max(0, ||f(x_anchor) - f(x_pos)||^2 - ||f(x_anchor) - f(x_neg)||^2 + margin)

This enforces that embeddings of the same identity cluster together, while different identities are separated by a margin.

3. DBSCAN Identity Clustering (Unsupervised Person Grouping)

To resolve raw unorganized face vectors, we apply **DBSCAN (Density-Based Spatial Clustering of Applications with Noise)** using Cosine Distance metric:

d_cosine(u, v) = 1 - (u · v) / (||u|| * ||v||)

With $\epsilon = 0.38$, DBSCAN groups all face occurrences into distinct, unique Person Identities, generating representative centroid vectors and thumbnail face avatars.
